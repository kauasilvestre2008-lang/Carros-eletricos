Site desenvolvido com HTML semântico e CSS, sem JavaScript, apresentando informações sobre carros elétricos.

# Estrutura do site

- Página inicial com título e menu de navegação.
- Três seções explicando como funcionam os carros elétricos, como recarregar e suas vantagens e desafios.
- Tabela comparando os tipos de veículos elétricos.
- Formulário de contato com campos para nome, e-mail e mensagem.
- Barra lateral com dicas e curiosidades.
- Rodapé com informações do autor.
- Cores em tons de verde e pêssego.
- Layout organizado com CSS Grid.
- Três imagens ilustrativas em SVG.
- Design responsivo para celulares e computadores.
- Botões e campos com destaque ao receber foco.
- HTML5 semântico.
- CSS externo.
- Formulário com validação.
- Acessibilidade e navegação por teclado.
